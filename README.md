## 朴素贝叶斯原理详解

### 1. 贝叶斯定理

对于两个事件 $A$、$B$，由条件概率的定义：

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)},\qquad P(B \mid A) = \frac{P(A \cap B)}{P(A)}$$

两式消去 $P(A\cap B)$ 即得 **贝叶斯定理**：

$$\boxed{P(A \mid B) = \frac{P(B \mid A)\,P(A)}{P(B)}}$$

在分类问题里把 $A$ 换成类别 $c$，$B$ 换成观测到的特征 $\mathbf{w}$：

$$P(c \mid \mathbf{w}) = \frac{P(\mathbf{w} \mid c)\,P(c)}{P(\mathbf{w})}$$

| 名称 | 符号 | 含义（以垃圾邮件为例） |
|---|---|---|
| 先验概率 prior | $P(c)$ | 还没看邮件内容时，一封邮件是垃圾邮件的概率 |
| 似然 likelihood | $P(\mathbf{w}\mid c)$ | 如果它是垃圾邮件，出现这些词的概率 |
| 证据 evidence | $P(\mathbf{w})$ | 出现这些词的总体概率（对所有类别相同） |
| 后验概率 posterior | $P(c\mid\mathbf{w})$ | 看到这些词之后，它是垃圾邮件的概率 |

贝叶斯定理的直观含义：**用观测到的证据去更新先验信念**。“free”“viagra”这类词在垃圾邮件中出现的概率远高于正常邮件，看到它们之后，“是垃圾邮件”的后验概率就会被显著抬高。

### 2. 用贝叶斯定理做分类

分类规则是 **选后验概率最大的类别**（最大后验估计，MAP）：

$$\hat{c} = \arg\max_{c}\; P(c \mid \mathbf{w}) = \arg\max_{c}\; \frac{P(\mathbf{w}\mid c)\,P(c)}{P(\mathbf{w})}$$

由于分母 $P(\mathbf{w})$ 对每个类别都一样，比较大小时可以直接去掉：

$$\hat{c} = \arg\max_{c}\; P(\mathbf{w}\mid c)\,P(c)$$

对二分类（1 = 垃圾，0 = 正常），就是比较 $P(\mathbf{w}\mid 1)P(1)$ 与 $P(\mathbf{w}\mid 0)P(0)$ 谁大。

### 3. “朴素”的条件独立假设

一封邮件的特征 $\mathbf{w} = (w_1, w_2, \dots, w_n)$ 由许多词组成。要直接估计联合分布 $P(w_1,\dots,w_n\mid c)$，参数个数随词表大小指数增长——词表有 5000 个词时，需要 $2^{5000}$ 个参数，不可能从 50 封邮件中学出来。

朴素贝叶斯做了一个大胆的简化——**在给定类别的条件下，各个特征相互独立**：

$$P(w_1, w_2, \dots, w_n \mid c) = \prod_{i=1}^{n} P(w_i \mid c)$$

于是分类规则变为：

$$\boxed{\hat{c} = \arg\max_{c}\; P(c)\prod_{i=1}^{n} P(w_i \mid c)}$$

参数个数从指数级降到 **类别数 × 词表大小**，这正是它“朴素”（naive）之处。现实中这个假设显然不成立（“bacon”后面跟“delicious”的概率比跟“unhealthy”高），但实践证明朴素贝叶斯在文本分类上依然效果很好：分类只需要 **后验概率的排序** 正确，而不需要概率值本身精确。

### 4. 文本表示：词集模型与词袋模型

先把所有文档中出现过的词去重，得到词表（`createVocabList`），再把每篇文档转成和词表等长的向量：

| 模型 | 函数 | 向量元素 | 例：词表 `[dog, my, stupid]`，文档 `my dog my` |
|---|---|---|---|
| 词集模型 set-of-words | `setOfWords2Vec` | 词 **是否出现**（0/1） | `[1, 1, 0]` |
| 词袋模型 bag-of-words | `bagOfWords2VecMN` | 词 **出现次数** | `[1, 2, 0]` |

词袋模型保留了词频信息（一封邮件里反复出现“free”比只出现一次更可疑），垃圾邮件和 RSS 实验都使用词袋模型。

文本切分由 `textParse` 完成：按非字母数字字符 `\W+` 切分、统一转小写、丢弃长度 ≤ 2 的词（如 “a”“is”“to”，以及 URL 拆出来的 “py”“en” 等碎片）。

### 5. 参数估计：极大似然估计

需要从训练集估计两类参数（这里使用多项式模型，词袋向量作为计数）：

**先验概率**：

$$P(c=1) = \frac{\text{垃圾邮件数}}{\text{邮件总数}}$$

**条件概率**：词 $w_i$ 在类别 $c$ 中出现的次数，占类别 $c$ 所有词出现总次数的比例：

$$P(w_i \mid c) = \frac{N_{c,i}}{N_c},\qquad N_{c,i} = \sum_{d \in c} x_{d,i},\quad N_c = \sum_{i} N_{c,i}$$

其中 $x_{d,i}$ 是文档 $d$ 的词向量第 $i$ 维。这就是 `trainNB0` 中 `p1Num / p1Denom` 的含义：`p1Num` 是一个向量，逐个累加所有垃圾邮件的词向量；`p1Denom` 是一个标量，累加垃圾邮件中的总词数。

### 6. 零概率问题与拉普拉斯平滑

如果某个词在训练集的垃圾邮件中从未出现，那么 $P(w_i\mid 1)=0$，而连乘中只要有一个 0，整封邮件属于该类的概率就变成 0——**一个没见过的词就能一票否决**，这显然不合理。

解决办法是 **拉普拉斯平滑（Laplace smoothing，加一平滑）**：给每个词的计数都加上 1：

$$P(w_i \mid c) = \frac{N_{c,i} + 1}{N_c + |V|}$$

其中 $|V|$ 是词表大小，保证所有词的概率之和仍为 1。可以理解为“在看数据之前，先假设每个词都已经出现过一次”。

> 本书代码的实现是 `np.ones(numWords)` 作为分子初值（对应 +1），分母初值为 `2.0`（而不是 $|V|$）。这样得到的值求和不严格等于 1，但对每个类别的影响是一致的平移，基本不影响分类结果。

### 7. 下溢问题与对数变换

每个 $P(w_i\mid c)$ 都是很小的数（例如 0.001），几百个相乘后会小于浮点数能表示的最小值（约 $10^{-308}$），被四舍五入成 0，这叫 **下溢（underflow）**。

由于 $\ln$ 是单调递增函数，$\arg\max$ 的结果不变，于是对连乘取对数，把乘法变成加法：

$$\ln\!\Big(P(c)\prod_{i} P(w_i\mid c)^{x_i}\Big) = \ln P(c) + \sum_{i} x_i \ln P(w_i\mid c)$$

最终的分类函数 `classifyNB` 正是这个式子：

```python
p1 = sum(vec2Classify * p1Vec) + np.log(pClass1)        # ln P(w|1) + ln P(1)
p0 = sum(vec2Classify * p0Vec) + np.log(1.0 - pClass1)  # ln P(w|0) + ln P(0)
```

其中 `p1Vec = np.log(p1Num/p1Denom)` 已经在训练阶段取过对数，`vec2Classify` 是词袋向量 $x_i$（词出现几次，对数概率就加几次）。

### 8. 完整推导示例

假设训练集只有 4 封邮件，词表为 `[free, money, meeting, lunch]`（$|V|=4$）：

| 邮件 | 类别 | free | money | meeting | lunch |
|---|---|---|---|---|---|
| d1 | 垃圾 | 2 | 1 | 0 | 0 |
| d2 | 垃圾 | 1 | 1 | 0 | 0 |
| d3 | 正常 | 0 | 0 | 1 | 1 |
| d4 | 正常 | 1 | 0 | 1 | 0 |

**① 先验**：$P(\text{垃圾}) = 2/4 = 0.5$，$P(\text{正常}) = 0.5$

**② 带平滑的条件概率**（垃圾邮件总词数 $N_1=5$，正常邮件 $N_0=4$）：

| 词 | $P(w\mid\text{垃圾}) = \frac{N_{1,i}+1}{5+4}$ | $P(w\mid\text{正常}) = \frac{N_{0,i}+1}{4+4}$ |
|---|---|---|
| free | (3+1)/9 = 0.444 | (1+1)/8 = 0.250 |
| money | (2+1)/9 = 0.333 | (0+1)/8 = 0.125 |
| meeting | (0+1)/9 = 0.111 | (2+1)/8 = 0.375 |
| lunch | (0+1)/9 = 0.111 | (1+1)/8 = 0.250 |

**③ 分类新邮件** “free money free”，词袋向量 $x = [2, 1, 0, 0]$：

$$\text{垃圾}:\ \ln 0.5 + 2\ln 0.444 + \ln 0.333 = -0.693 - 1.622 - 1.099 = -3.414$$

$$\text{正常}:\ \ln 0.5 + 2\ln 0.250 + \ln 0.125 = -0.693 - 2.773 - 2.079 = -5.545$$

$-3.414 > -5.545$，判为 **垃圾邮件**。换算回概率：$P(\text{垃圾}\mid x) = \frac{e^{-3.414}}{e^{-3.414}+e^{-5.545}} \approx 89.4\%$。

注意即使 “money” 从未在正常邮件中出现，平滑后它在正常类中的概率仍是 0.125 而不是 0，正常类的得分不会被直接清零。

### 9. 优缺点

**优点**
- 训练只需计数一遍数据，时间复杂度 $O(\text{文档数}\times\text{词表大小})$，非常快
- 小样本下也能工作（本项目只有 50 封邮件）
- 可增量更新：来一封新邮件只需更新计数
- 可解释性强：`p1V - p0V` 越大的词，越能代表垃圾邮件

**缺点**
- 条件独立假设过强，忽略了词序和词之间的关联
- 输出的概率值往往过于极端（接近 0 或 1），不宜直接当置信度使用
- 对输入数据的表示方式（分词、停用词）敏感

## 实验结果

- **垃圾邮件**：每次随机抽 10 封作为测试集，错误率通常为 **0 ~ 10%**。由于划分是随机的，建议多次运行取平均（书中称平均错误率约 6%）。
- **RSS 地域分类**：书中原本使用的 Craigslist RSS 已下线，这里改为 NYT 纽约地区新闻（类别 1）与 SFGate 湾区新闻（类别 0）。两个源可用的条目只有十几条，训练集很小，错误率波动较大（约 40% ~ 55%），主要用于演示特征词提取。
